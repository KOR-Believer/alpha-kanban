# 독서 기록 앱 계획

소개 페이지와 README에 사용하는 가상 프로젝트입니다. 아래 상태와 기록은 예시이며 실제 개발 결과가 아닙니다.

## 목표

읽은 책을 기록하고 제목으로 다시 찾는다. 작은 기능부터 검토하고 구현한다.

## 이번에 만들 기능

- 책 제목·저자·읽기 상태를 기록한다.
- 제목 검색과 읽은 책 필터를 함께 사용한다.
- 기록을 수정하고 확인 후 삭제한다.
- 제목순·최근 기록순으로 정렬한다.

## 합의한 범위

필터는 현재 방문 동안 유지한다. 독서 메모 본문 검색은 이번 범위에서 제외한다. 작은 화면에서는 검색창 아래에 필터를 놓는다.
