# Windows 스킬 폴더 연결 확인

저장소 체크아웃이나 pnpm은 필요하지 않습니다. Node.js가 설치된 PC에서 ZIP을 전부 풀어 사용하세요. 개인 스킬 대신 이 ZIP의 `fixtures` 폴더만 연결합니다.

1. `run-windows.cmd`를 실행하고 창을 열어 둡니다.
2. Chrome에서 <http://127.0.0.1:5251/report.html>을 엽니다.
3. 화면의 확인 순서에 따라 앱에서 폴더 드롭·선택·재허용을 확인합니다. 실제 스킬 업데이트·재설치·복원 적용은 누르지 않습니다.
4. 결과를 선택하고 메모를 적은 뒤 결과 JSON을 저장합니다.
5. `verify-windows.cmd`를 실행해 원본 합성 파일의 변경 여부를 확인합니다.
6. 내려받은 결과 JSON과 `fixture-verification.json`을 함께 전달합니다. 실패한 경우 보이는 오류 문구나 화면도 남겨주세요.

이 묶음에서는 스킬 호환성 확인 안내가 나와 일반 업데이트를 할 수 없는 것이 정상입니다. 연결과 변경 비교까지만 확인합니다. 파일 검사 결과의 `ignoredMetadata`는 Finder/탐색기가 만든 `.DS_Store`, `Thumbs.db`, `desktop.ini`를 스킬 파일과 구분한 항목입니다.

접근 재허용 확인은 이 테스트 주소의 사이트 정보 → 파일 편집 권한에서만 수행합니다. 다른 Alpha Kanban 주소의 연결·브라우저 데이터·권한을 지우지 않습니다. 끝나면 서버 창에서 Ctrl+C를 누릅니다.
