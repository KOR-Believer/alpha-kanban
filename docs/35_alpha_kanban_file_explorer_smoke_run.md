## 메모

개발 화면의 선행 확인과 분리해 배포용 빌드를 실제 조작한다. Windows·Edge는 이 회차의 환경이 아니다. 계측은 시험 페이지에만 추가하고 앱 원본에는 포함하지 않는다. 측정하지 않은 변경 전 속도는 비교값으로 제시하지 않는다.

## 실행 당시 공통 조건

파일 탐색 기능의 실제 PC 브라우저 회귀 기준이다. 개인 프로젝트 대신 Markdown 500개 이상과 코드·이미지·다중 페이지 PDF·HTML·바이너리로 구성한 합성 프로젝트를 연결한다. `.ak.config`의 작업 폴더는 `contexts`로 두고 `contexts-old`와 작업 폴더 밖 Markdown도 준비한다.

폴더 선택은 시험 폴더만 대상으로 한다. 스킬 설치·업데이트, 원본 이동·문서 저장·배포는 수행하지 않는다. 권한 검사는 시험용 origin과 연결에만 적용한다. 파일 소실 사례는 합성 파일을 잠시 다른 이름으로 바꿨다가 원래 바이트로 복구한다. 읽기 검증 전후 파일 해시를 대조한다.

자동 검사 결과와 실제 조작 결과를 구분한다. 브라우저·운영체제가 달라지면 새 회차로 기록한다. PDF 화면은 브라우저 내장 뷰어를 직접 확인하고, HTML은 통제된 외부 리소스만 사용한다. 성능 수치는 계측한 조건과 함께 기록하며 측정하지 않은 변경 전 수치를 추정하지 않는다.
