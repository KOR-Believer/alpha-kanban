# Alpha Kanban 브라우저 전환 후 작업 구분 인벤토리

작성일: 2026-10-18
수정일: 2026-10-18

## 결론

현재 제품은 로컬 Markdown을 읽고 수정하는 브라우저 앱이다. AI와의 논의·구현은 외부 도구에서 수행한다. AKR-01에서 제거한 서버·채팅·실행기를 과거 티켓에 따라 다시 만들지 않는다.

- 실행 하네스 AKH-01~08과 자율 실행 NVD-01~12, 총 20개 계획을 폐기한다. 제목에 `[폐기]`를 붙이고 `DEFERRED`로 구분한다. 이미 보류였던 AKH-08을 제외하면 상태 변경은 19개다.
- DONE 티켓은 당시 완료한 이력이다. 기능을 제거했다고 다시 열거나 삭제하지 않는다. 미완료 작업도 폐기를 이유로 DONE 처리하지 않는다.
- 헤더·문서 탐색·안전한 저장·스킬 호환·PWA·소개 개선은 유효하다. 일부 과거 서버 조건만 종료하고 기존 상태와 실제 검증 공백을 보존한다.

## 조사 범위와 근거

- 범위: `docs/01`~`docs/20`의 계획·티켓과 현재 앱 구조. 파일 이름·티켓 ID는 유지한다.
- 기준: `master`의 `362c5ca`, [AKR-01](18_browser_only_tickets.md), `AGENTS.md`, 루트 `package.json`, `apps/web/src/browserOnly.test.ts`, `packages/shared/src/ticketMarkdown.ts`.
- 사용자 요청: 2026-10-18 브라우저 버전으로 방향을 바꾸면서 폐기된 기능의 기존 플랜·티켓을 정리한다. 구현·배포가 아니라 문서 정리다.
- 한계: 현재 코드의 기능 존재와 기록된 검증 범위를 대조했다. 이번 정리에서 실제 폴더 권한·다른 PC·PWA 설치를 재검증하지 않았다.

## 현재 유효한 후속 작업

- **브라우저 사용 검증:** AKL-01~06의 실제 OS 폴더 선택·권한·외부 수정·충돌·재연결·다른 PC 확인. 기존 자동 테스트와 실제 사용자 환경의 증거는 구분한다.
- **스킬·문서 계약:** AKL-07의 Claude 포팅, AKL-10~13의 버전·하위 호환·안전한 설치/업데이트·공통 안내. API 서버를 대상으로 하던 AKL-11 조건은 공용 로직과 독립 CLI 계약으로 좁힌다.
- **화면 검증:** AGH-01~04/06의 남은 화면 검증, AKL-15의 기존 소개 적용·검증 이력. 새 소개 구성은 AKI-01~03이 담당하며 옛 시안 승인이 새 시안 승인을 대신하지 않는다.
- **PWA:** AKP-01~06의 기록된 미확인 실제 환경 항목. 연결·설정 보존은 계속 요구한다.
- **보류 후보:** AGH-05의 문서 세트 context strip은 브라우저 전환으로 폐기된 기능이 아니므로 기존 보류를 유지한다.

## 기록 해석

- 현재 상태 목록에 취소 전용 값이 없어 폐기는 `DEFERRED`와 `[폐기]` 제목·목표·사유 메모로 나타낸다. 일반 보류와 달리 자동 착수 후보가 아니며 재도입은 별도 제품 결정이 필요하다.
- 진행률·완료 시각·사용자 지시·기존 메모는 보존한다. 불필요해진 검증은 `N/A`로 설명하고 수행하지 않은 검사를 체크하지 않는다.
- 문서의 `현재 진행률`은 기존 계약대로 `DONE / 전체 티켓`이다. 폐기 티켓도 분모에 있으므로 폐기 문서를 100%로 만들지 않는다.
- 폐기 문서의 옛 목표·범위·질문은 설계 이력이다. 현재 질문과 구분하고, 유효한 작업의 범위에서 서버 보존 요구가 남지 않도록 정리한다.
- 개인 스킬·운영 데이터·앱 코드와 저장 형식은 이번 정리로 변경하지 않는다. 문서를 보드에서 숨기는 기능도 추가하지 않는다.

## 정리 검증

- 12개 티켓 문서 모두 `pnpm ticket-md check`와 동봉 `check-ledger.mjs`를 통과했다. 기존 02~12 문서는 레거시 검사, 14~20 문서는 엄격 검사를 적용했다.
- 변경 전후 공용 파서 결과에서 102개 티켓 ID·진행률·완료 시각·기존 사용자 지시를 대조했다. 55개 DONE 본문과 기존 체크된 증거는 동일하고, 폐기 대상 외 상태 변경은 없다. 삭제된 기능의 미수행 검사는 N/A로 바꾸고 서버 호환성 검사 대상만 현재 공용 로직으로 수정했다.
- 기존 진행 메모는 보존하고 폐기·범위 정리 메모 27개를 추가했다. 상대 Markdown 링크와 `git diff --check`를 확인했다. 앱 코드·전역 스킬 변경이나 커밋·푸시는 하지 않았다.
