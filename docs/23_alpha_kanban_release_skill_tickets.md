- 입력·다른 모달·투어를 방해하지 않고 팝오버/모달 포커스를 순서대로 전환한다. 적용은 AKP의 기존 초안·쓰기·다중 창 보호를 통과해야 한다.

제외 범위:

- OS 푸시, 종료된 앱의 정시 확인 보장, 무조건 새로고침·skipWaiting, 업데이트 엔진 재구현

완료 기준:

- [x] 적용 전에 해당 버전의 노트를 읽을 수 있고 취소·읽기만으로 경로나 문서·설치 상태가 바뀌지 않는다.
- [x] 기존 저장·초안 보호가 유지되고 알림/모달이 입력 초점을 빼앗지 않는다.

검증:

- [x] 발견/다운로드/준비/실패/보류/오프라인 상태, 반복 확인·다중 창·대상 교체와 알림 닫기 회귀
- [x] 한영·라이트/다크·좁은 화면·키보드·Escape·초점 복원 및 저장/초안 중 적용 보류 검증

- [x] 언제든 수동 재열람할 수 있고 첫 방문·다중 창·저장 실패에서도 문서·설정이 보존된다.

사용자 지시:
