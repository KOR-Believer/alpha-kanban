# 첫 사용 화면 안내 검증 기록

- 검증일: 2026-10-18
- 대상: AKO-01, AKO-02
- 환경: 로컬 브라우저 모드, Chrome 155.0.8059.85, Driver.js 1.10.1
- 연결된 개인 폴더와 기존 사용자 브라우저 설정은 변경하지 않았다. 자동화는 별도 브라우저 컨텍스트와 합성 Markdown/OPFS 폴더를 사용했다.

## 구현

- 시작 화면: 직접 연결 프로젝트와 워크스페이스가 모두 없는 조회 성공 상태에서만 둘러보기 제안. 사용자가 시작하면 프로젝트 열기와 워크스페이스 등록을 2단계로 안내한다.
- 프로젝트/전체 보드: 문서 선택 또는 프로젝트 필터, 상태 열, 티켓 카드의 3단계. 카드 없는 보드, 로딩, 오류, 열린 상세창에서는 제안하지 않는다.
- 사용 안내에서 다시 보기. 최초 안내는 자동 오버레이가 아니라 선택 가능한 제안이다.
- 완료와 건너뛰기 기록은 `alpha-kanban.tours.v1.start`, `alpha-kanban.tours.v1.board`에 저장한다. 두 보드가 기록을 공유하며 앱 배포 버전으로 초기화하지 않는다.
- 기존 shadcn 토큰과 Button variants를 사용한다. 안내는 파일·티켓·연결을 수정하거나 AI를 실행하지 않는다.

새 안내 관련 단위/통합 테스트 23개는 조회 중/오류/직접 연결/권한 상실의 표시 조건, StrictMode 정리, 대상 제거와 다른 모달 진입, 경로 변경, 언어 변경 시 현재 단계, 탭 간 기록 공유, 저장 실패의 세션 내 대체 기록, 원문 변경 API 미호출을 확인한다.

Chrome 스모크는 1360x900 및 390x844에서 실제 Driver.js를 사용했다. 건너뛰기 후 재방문, 사용 안내에서 재실행, 완료, Tab/화살표/Escape, 종료 후 포커스 복원, 프로젝트·전체 보드 3단계, 한영 전환, 팝오버 화면 내 배치와 28px 공통 버튼 높이를 확인했다. 안내 전후 합성 티켓 원문이 동일하고 상세 입력 초안도 유지됨을 검사했다.

## 검증 재현

- 안내·PWA 스모크는 실행별 결과와 화면 캡처를 Git 추적에서 제외된 `output/playwright/` 아래에 생성한다. 공개 저장소에는 위 결과 요약을 남긴다.
- 재실행: 브라우저 개발 서버가 실행 중일 때 `pnpm test:tours`. 다른 로컬 포트는 `TOUR_SMOKE_URL`로 지정한다.

## 검증 경계

- PWA 자동화의 설치는 CDP, 파일 핸들은 OPFS를 사용했다. 실제 OS 설치 버튼·폴더 선택 권한 창을 재검증한 것은 아니다.
- 공개 도메인, DNS, 배포 및 PWA 계획의 별도 출시 검증을 수행하거나 완료로 바꾸지 않았다.
- 사용자 데이터 삭제·권한 재설정·개인 전역 스킬 수정·커밋·푸시는 하지 않았다.

## 사용 안내 버튼 회귀 수정

- 2026-10-18 사용자 제보로 재확인: 시작 화면의 AI와 문서로 작업하기는 하단 요약에 `scrollIntoView`만 호출했다. Chrome에서 페이지 높이와 화면 높이가 모두 1242px인 경우 클릭 전후 스크롤 위치와 안내 위치가 같아 동작을 알아볼 수 없었다.
- 시작 화면·전체 보드의 같은 메뉴는 이제 기존 7단계 ProjectGuide를 공통 shadcn 모달로 연다. 현재 경로·보드·입력 상태를 유지하고, 본문만 스크롤하며, 닫으면 사용 안내 버튼으로 포커스가 돌아온다. 화면 둘러보기는 별도 메뉴로 유지한다.
- `pnpm test`: 327개 통과(shared 15, server 84, web 228). 두 진입점의 모달 표시·7단계 본문·언어 변경·닫기·포커스 복원·이동 및 문서 변경 미호출 회귀 테스트를 추가했다.
- 웹 타입 검사와 `pnpm build:browser` 통과. 큰 번들 경고는 기존과 같다.
- Chrome 개발 화면(5187)과 브라우저 빌드(4189)에서 각 7개 안내 스모크 시나리오 통과. 1360x900 및 390x844의 모달 배치와 본문 스크롤, 기존 투어 재실행을 확인했다. 4189에서는 중첩 스킬 설치 창을 닫은 후 안내로 돌아오는 동작도 확인했다.
- PWA 업데이트·복구 16개 전체 검사는 이 버튼 수정에서 다시 실행하지 않았다.

## AKO-03 상황별 상시 투어

- 2026-10-18: 최초 제안 중심의 짧은 안내를 현재 화면에서 직접 실행하는 안내로 확장했다. 기존 최초 검증 기록은 위에 남기며, 현재 동작은 이 항목을 기준으로 한다.
- 시작·프로젝트·전체 보드 상단에 화면 둘러보기를 상시 노출한다. 완료/건너뛰기 후에도 남고 사용 안내의 기존 재실행 경로도 유지한다. 상세창에는 상세 둘러보기를 별도로 제공한다.
- 시작 8단계: 프로젝트 열기, 워크스페이스 등록, 새 폴더, 목록 검색/정렬, 자동 열기, 연결 관리, 스킬 준비, AI 작업 흐름.
- 티켓이 있는 프로젝트 보드 9단계: 프로젝트 전환, 문서 검색/필터/정렬, Markdown 전환, 상태 열, 카드, 전체 티켓, 폴더 권한.
- 티켓이 있는 전체 보드 8단계: 프로젝트 선택, 검색, 완료 숨김, 상태 열, 카드, 프로젝트 이동, 표시 순서, 폴더 권한.
- 열린 티켓 상세 6단계: 보기 크기, 작업 범위, 완료 기준/검증, 선택적 상태 변경, 수동 지시, 진행 기록. 긴 내용은 제목이나 입력 폼을 짚어 과도하게 큰 영역을 강조하지 않는다.
- 실제로 렌더링된 대상만 사용한다. 카드 없는 검색 결과, 안내 화면, 일반 Markdown에서는 없는 단계를 제외하며 경로·검색·필터를 임의로 바꾸지 않는다. 좁은 화면에서 숨겨진 목록 대신 보이는 목록을 사용한다.
- `start`, `project`, `all`, `detail`의 `alpha-kanban.tours.v1.*` 기록을 사용한다. 기존 `board` 기록은 삭제하지 않고 두 보드의 최초 제안 판단에 반영한다. 빌드 버전에 따라 초기화하지 않는다.
- 상세 투어의 팝오버와 가림막은 기존 Radix 대화상자 내부에서 포커스와 포인터 경계를 공유한다. Escape는 투어만 닫고 작성 중인 입력을 유지한다. 중앙 창 좌표와 가림막 생성 시점을 실제 클릭 테스트로 확인했다. 좁은 상세창의 도구 모음은 한영 모두 줄바꿈하여 닫기와 프로젝트 이동을 가리지 않는다.

- Chrome은 1360x900·390x844에서 각 투어의 모든 단계, 예상 단계 수, 화면 내 배치와 공유 버튼 크기를 검사했다. 상세 side/modal/full, 전체 보드 상세의 한영 도구 모음, 완료 뒤 직접 재실행, 안내 페이지에서 보드 재실행, 필터 결과 없음, 일반 Markdown과 안내 화면을 포함한다.
- 합성 Markdown 원문, 저장하지 않은 수동 지시, 다른 창의 초안, 현재 문서 URL과 검색 문자열을 보존했다. 단위 테스트는 삭제/숨김 대상, 경로·모달 전환, 이전 공유 기록 호환과 별도 화면 기록을 검사한다.
- 사용자 Chrome은 기존 보드의 진입점 확인에만 사용했다. 자동화는 별도 Chrome 컨텍스트와 OPFS 합성 파일을 사용했다. 실제 OS 폴더 권한·설치 UI, 배포 도메인, PWA 업데이트/복구 전체 시나리오는 이번 변경에서 재검증하지 않았다. 사용자 연결·전역 스킬·외부 프로젝트 문서는 변경하지 않았으며 배포·커밋·푸시는 하지 않았다.

## AKO-03 도움말 통합

- 2026-10-18 후속 결정: 상단의 상시 둘러보기·사용 안내·소개 버튼을 도움말 하나로 합쳤다. 메뉴 순서는 화면 둘러보기 / AI와 계획·티켓 만들기 / Alpha Kanban 소개이며 시작·프로젝트·전체 보드가 공유한다. 위의 상시 독립 버튼 기록은 이전 검증 이력이다.
- AI 안내는 현재 화면 위의 기존 7단계 모달로 열고 닫으면 도움말로 포커스를 돌린다. 소개만 /intro로 이동한다. 상세창 투어와 사이드바 사용 안내는 유지한다. 한영 README의 실제 메뉴 경로도 맞췄다.
- `alpha-kanban.tours.v1.<surface>.offered`로 제안 표시를 별도 기록한다. 완료/건너뛰기를 하지 않아도 새로고침·재방문에 반복하지 않는다. 프로젝트나 문서를 바꿨다가 돌아와도 이전 제안을 되살리지 않는다. 로딩·오류·부적격 화면에서는 첫 표시 기회를 소비하지 않으며 기존 완료/건너뛰기와 공유 board 기록을 존중한다.
- `pnpm test` 278개 통과(shared 41, web 237), `pnpm typecheck`, `pnpm build`, `git diff --check` 통과. 빌드의 기존 큰 번들 경고는 유지된다.
- Chrome 개발 5187과 정적 빌드 4189에서 각각 8개 확장 시나리오를 확인했다. 메뉴 순서와 소개 이동·돌아오기, 무응답 첫 방문 뒤 제안 숨김, 도움말 재실행, 각 화면의 AI 안내, 한영 전환, 1360x900·390x844, 상세 side/modal/full, 초안·합성 Markdown·검색 조건 보존을 포함한다.
- 자동화는 격리된 Chrome 컨텍스트와 OPFS 합성 문서로 실행했다. 실제 사용자 폴더 연결·설정을 변경하지 않았다. PWA 업데이트/복구 전체 및 OS 설치/권한 창은 이번 도움말 수정에서 재검증하지 않았다. 커밋·푸시·배포하지 않았다.
