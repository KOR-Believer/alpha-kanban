구현 범위:

- 플로팅은 왼쪽 아래를 기준으로 위·오른쪽 가장자리와 모서리에서 조절한다. 최소 크기는 기존 시안의 368×540px이며 화면이 작을 때만 표시 크기를 제한한다.
- 배치·보기·크기를 브라우저 표시 설정으로 기억한다. 고정/플로팅의 크기는 따로 유지하며 확대·접힘 때문에 문서나 보드·초안을 다시 생성하지 않는다.
- 기존 URL, 새 탭 링크, 문서 묶음, 본문 검색, 읽기·쓰기 보호, 소유자 판정과 전체보드 필터를 유지한다.
- 관련 투어 앵커와 한영 안내를 새 컨트롤에 맞춘다.

제외 범위:

- Markdown·개인 스킬·폴더 연결 변경, 파일 이동, 전체보드 재배치, 배포

### ADP-02. 상태바에서 묶음 문서 전환과 검색

목표:

- 문서 패널을 펼치기 전에도 하단 상태바에서 같은 묶음의 다른 문서로 전환하고 통합검색을 시작한다.

현재 문제:

- 상태바의 문서 유형은 표시만 하며 검색은 패널 안에서만 시작할 수 있다.

구현 범위:

- 현재 문서 유형을 눌러 같은 묶음의 문서를 고르는 팝오버를 연다. 다른 문서가 없으면 표시만 한다.
- 기존 묶음의 전체 파일을 사용하고 현재 선택과 파일 경로를 보여준다. 기존 탐색·초안 보호와 휠 클릭 새 탭 동작을 재사용한다.
- 하단 검색은 기본 돋보기 버튼으로 표시하고 클릭하면 입력란을 펼친다. 검색어가 있으면 펼친 채 유지하고 빈 입력에서 포커스가 벗어나면 접는다.
- 패널 통합검색과 같은 검색어·결과를 사용한다. 하단에서 검색을 시작하면 현재 배치를 유지하면서 문서 패널을 열어 결과를 보여준다.
- 한영·라이트/다크·좁은 화면을 지원한다.

제외 범위:

- 묶음·슬러그 판정 변경, 검색 범위·색인 변경, Markdown·개인 스킬·연결 변경, 배포

완료 기준:

- [x] 유형 팝오버에서 필터로 숨겨진 문서도 같은 묶음이면 전환할 수 있고, 단독 문서는 불필요한 메뉴를 만들지 않는다.
- [x] 문서 전환 링크의 새 탭 열기와 기존 탐색 보호가 유지된다.
- [x] 하단 검색의 펼침·유지·접힘이 입력 상태에 맞고 패널 검색어와 동기화된다.
- [x] 검색과 팝오버는 문서·티켓을 저장하지 않고 좁은 화면에서도 조작 가능하다.

검증:

- [x] 전환·검색 상호작용 회귀 테스트와 타입 검사·빌드
- [x] 합성 문서를 사용한 실제 Chrome의 팝오버·검색·좁은 화면 검증

사용자 지시:

- 2026-11-09: 하단의 티켓 표시에서 같은 묶음의 인벤토리 등으로 플로팅 전환하고, 검색은 평소 돋보기 버튼으로 두되 입력된 검색어가 있으면 입력란을 펼쳐둔다.
- 2026-11-09: 검색은 문서 패널의 기존 입력을 접는 대신 하단 상태바에 추가한다.

진행 메모:
