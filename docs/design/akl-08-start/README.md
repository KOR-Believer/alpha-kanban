# AKL-08 시작 화면 디자인 검토

## 결과와 참조

- 2026-10-18: 시작 화면 시안 승인 후 AKL-09로 실제 앱에 적용했다. 이 문서는 시안 단계의 결정과 검증 기록이다.
- [요구사항](brief.md) · [AKL 티켓](../../14_alpha_kanban_browser_local_tickets.md) · [제품 적용 검증](../../../design-qa.md)
- 현재 작업 화면: [Alpha Kanban](https://kanban.giveit2.me/). 로컬 실행은 [기여 가이드](../../../CONTRIBUTING.md)를 참고한다.

## 설계와 결정

- Open Design으로 가상 데이터 기반 시안을 만들고 기존 제품 테마에 적용하는 흐름으로 검토했다.
- 데스크톱은 최근 5개 / 다른 25개 목록, 목록별 검색·정렬, 독립 내부 스크롤이다. 워크스페이스 관리와 AI 작업 흐름·스킬 설치 진입점이 아래에 이어진다.
- 좁은 화면에서는 최근/다른 목록을 탭으로 전환하며 안내는 페이지 스크롤로 접근한다. 이 배치를 포함한 시작 화면 시안을 사용자가 승인했다.
- 많은 프로젝트, 최근 기록 없음, 연결 폴더 없음, 권한 재연결, 검색 결과 없음과 한국어/영어 상태를 검토했다.
- 시안의 등록·새 프로젝트·재연결·설치는 합성 데이터 기반 시뮬레이션이었다. 실제 설치 출처·버전 연결과 React 컴포넌트 적용은 별도 구현 범위로 구분했다.

## 당시 검증 범위

- Chrome에서 기본 화면과 상태별 검토 화면을 확인하고 Playwright로 아래 동작을 검사했다.
- 1440×900과 1920×1080: 양쪽 목록의 상단·높이 일치, 목록 간 중복과 가로 넘침 없음. 내부 목록 높이는 각각 251px / 301px이었다.
- 최근 기록 없음은 0 / 30, 폴더 없음은 0 / 0이며 임의의 최근 항목을 만들지 않았다.
- 390×844 한글·영문: 가로 넘침 없음, 최근 목록만 표시되고 다른 목록은 탭 뒤에 있었다.
- 한쪽 목록을 스크롤해도 다른 쪽 목록과 제목 위치가 유지됐다. 자동 열기 체크는 현재 URL을 바꾸지 않았다.
- 목록 검색, 설치 안내 모달 열기와 Escape 닫기를 확인했다. 페이지 실행 오류는 없었으며 시안 호스트의 favicon 404는 별도로 확인했다.
- 실제 OS 폴더 권한, 스킬 설치, AI 실행, 실제 모바일 기기 터치는 검사하지 않았다. 시안 결과를 제품 전체 검증으로 취급하지 않는다.

## 적용 경계

- 시안에는 가상 데이터와 요구사항만 사용했고 개인 프로젝트 데이터·폴더 권한·AI 설정은 포함하지 않았다.
- 후속 지시로 AKL-09 실제 적용과 공통 설치 안내 UI를 진행했다. 버전 계약과 격리 설치 검증은 AKL-13에서 별도로 추적한다.
- 생성, 브라우저 검증, 사용자 승인, 제품 적용은 각각 구분한다.

## 확인·결정이 필요한 사항

- 없음. 시안 승인과 후속 제품 적용 결정을 기록했으며 남은 구현 상태는 티켓에서 관리한다.
