# AKL-14 소개 랜딩 디자인 검토

## 결과와 참조

- 2026-10-18: Open Design으로 소개 시안을 생성·보정했고 사용자가 시작 화면과 소개 랜딩 시안을 승인했다. 이 문서는 당시 설계와 검증 기록이다.
- 후속 지시에 따라 `/`는 프로젝트 작업 화면, `/intro`는 별도 소개로 구현했다. 현재 페이지는 [소개·설치 안내](https://kanban.giveit2.me/intro)에서 확인한다.
- 실제 프로젝트 캡처는 사용자 피드백에 따라 제거했다. 가상 책갈피 보드와 같은 데이터의 Markdown을 기존 shadcn 테마로 렌더한다.
- 앱 내부 보드 개선 시안은 채택하지 않았다. 시작·소개만 적용했다.

## 설계와 결정

- Open Design으로 별도 가상 데이터 시안을 만들었다. 이전 시작 화면은 읽기 참고만 했으며 실제 프로젝트 데이터와 개인 설정은 사용하지 않았다.
- 헤더·제품명·제품 예시, 작업 흐름, 로컬 원본과 권한, 스킬 안내, 시작 화면 이동으로 구성했다. 한국어 기본이며 영어로 전환한다.
- 예시 상태를 실제 여섯 상태에 맞추고 Markdown은 정식 Status/Progress/사용자 지시 발췌와 공통 reading 파일명을 사용했다. 데스크톱 Chrome 안내와 로컬 Lucide 아이콘·라이선스를 포함했다.
- 시안의 Claude/버전 준비 안내는 후속 결정에 따라 실제 제품에서 제거하고 티켓에서만 추적한다.

## 당시 검증 범위

- Chrome에서 이미지·아이콘 로드를 확인했다. 1440×900에서 페이지 폭 1425px로 가로 넘침이 없었다.
- 390×844에서 한국어·영어의 페이지 폭은 375px이며 검사한 본문 요소에 수평 넘침이 없었다. 실제 모바일 기기의 파일 권한 지원을 검사한 것은 아니다.
- 설치 안내 모달 열기, Escape 닫기와 언어 왕복을 확인했다. 시작 화면 시안으로 이동하고 뒤로가기로 복귀했다.
- 내보낸 1440×2534 전체 페이지 이미지는 시안 검토 자료이며 실제 사용자 프로젝트 캡처가 아니다.
- 정적 시안은 링크 이동·언어 전환·모달·클립보드 요청만 사용했다. 파일 선택, 제품 IndexedDB, API 호출, 스킬 설치 및 AI 실행은 포함하지 않았다.
- 시안의 자동 검사는 DOM 대역 테스트였다. 실제 클립보드 쓰기/권한 거부, 모바일 기기, 실제 스킬 설치, 제품 앱 전체 회귀 테스트는 검사하지 않았다.

## 확인·결정이 필요한 사항

- 없음. 실제 앱 적용과 마크업 데모 사용은 확정했다. 배포 버전 계약과 공유 이미지 등 남은 구현 상태는 AKL-13/15에서 관리한다.
