# AKL-14 소개 랜딩 시안

작성일: 2026-10-18
상태: 과거 시안 제작 요구사항. 승인·적용 결과는 [디자인 검토](README.md), 현재 제품 지침은 [AGENTS.md](../../../AGENTS.md)를 참고한다.

## 확정한 목적과 경계

- `/`는 프로젝트 시작 화면으로 유지한다. 별도 `/intro`는 Alpha Kanban을 처음 접하는 사람에게 소개하고 외부 공유에 쓰는 페이지다.
- 같은 앱 안의 두 화면이지 별도 사이트·배포가 아니다. 시작 화면의 최근/다른 프로젝트 목록을 소개에 다시 넣지 않는다.
- Open Design의 별도 디자인 프로젝트 안에서만 시안을 만든다. 실제 앱, 이전 AKL-08 디자인, 개인 전역 스킬, 폴더 권한·데이터·설정을 수정하지 않는다.
- 이번 산출물은 디자인 검토용 HTML과 캡처다. `/intro`의 제품 라우트 구현, 공개 배포, 실제 스킬 설치, AI 실행은 하지 않는다.

## 방문자와 전달할 내용

Alpha Kanban은 AI와 사람이 같은 로컬 Markdown을 보며 일하도록 돕는 칸반이다. 웹이 AI를 실행하거나 자동 오케스트레이션하는 서비스가 아니다.

1. 문서가 없어도 외부 AI에서 만들고 싶은 기능과 사양을 논의한다.
2. implementation-ledger로 plan/tickets를 작성하고 필요한 경우 inventory를 더한다.
3. 프로젝트 폴더를 연결해 문서를 읽고 티켓 상태 변경 사유와 수동 지시를 같은 Markdown에 기록한다.
4. AI 도구에 최신 Markdown을 다시 읽고 구현하도록 요청한다. 검토와 구현을 반복한다.

호환 Markdown이 이미 있으면 스킬 설치 없이 사용한다. Codex용 동봉 스킬을 기준으로 안내하고 Claude 포팅·실행 검증은 후속 예정으로 구분한다. 문서 형식 개방과 모든 AI에서의 설치 지원을 혼동하지 않는다.

## 구성과 주요 동작

- 간결한 헤더: 브랜드, 작업 흐름/스킬 안내 앵커, 작은 언어 전환, 시작하기. H1은 `Alpha Kanban`이다.
- 첫 화면: 제품 이름, 짧은 설명, 시작하기, 읽을 수 있는 실제 UI 기반 칸반 예시. 과도한 거대 히어로로 다음 내용을 모두 아래로 밀지 않는다.
- 제품 화면 중심의 unframed/full-width 구성을 사용한다. 텍스트와 장식 카드가 좌우로 갈라진 히어로, 사진·그라디언트·장식 도형·가짜 코딩 화면은 사용하지 않는다. 브랜드 문구는 화면 매체의 여백 위에 두되 티켓 본문과 겹치지 않게 한다.
- 작업 흐름: 위의 네 단계를 짧은 한국어로 설명한다. 기능 이름만 나열하는 네 개의 큰 카드 대신 연결된 흐름과 구체적인 문서/칸반 예제를 보여준다.
- 원본과 경계: 로컬 Markdown 원본, 사용자의 명시적 폴더 권한, 문서를 서버에 업로드하지 않는 흐름, 웹에서 AI를 실행하지 않음. 불변 보안 보장·실시간 자동 동기화 보장은 하지 않는다.
- 스킬 시작 안내: 설치 요청문 확인/복사와 GitHub 원본 보기. ZIP은 보조 선택지다. 실제 배포 태그·형식 버전은 준비 중이며 설치된 개인 스킬 버전은 확인하지 않는다고 표시한다. 준비되지 않은 주소를 만들어 연결하지 않는다.
- 설치 요청 시안은 공식 저장소의 동봉 스킬을 확인하고 전체 폴더·기존 개인 수정 보존을 요구하는 예시로 표시한다. 시안에서 설치를 실행하지 않는다.
- 끝부분에서 시작 동작을 다시 제공한다. 폴더 연결 없이 설명과 시안을 읽을 수 있어야 한다.
- 시안의 시작하기/브랜드 홈 동작은 기존 AKL-08 미리보기로 연결한다. README에 제품 적용 시 대상이 `/`임을 기록한다. 공개 운영 사이트나 실제 사용자 프로젝트로 이동시키지 않는다.

## 기존 디자인과 제품 참조

- 디자인 기준은 alpha-kanban의 `apps/web/src/styles.css`, shadcn b1, Raleway Variable + 시스템 한글, Lucide다. 기존 AKL-08의 BRIEF.md와 assets는 읽기 참고만 가능하다.
- 밝은 중립 배경과 짙은 잉크색, 가는 테두리, 제한된 acid-green 강조를 유지한다. 기존 테마를 새 팔레트나 노션 테마로 교체하지 않는다.
- 자간은 0, 폰트 크기는 viewport 단위로 스케일하지 않는다. 데스크톱·모바일의 고정 breakpoint 크기를 사용한다. 기본 버튼 32px, 작은 도구 28px, 모바일 주요 동작은 충분한 터치 영역을 갖는다.
- 페이지 섹션은 full-width band 또는 테두리 없는 안쪽 레이아웃이다. 반복 티켓과 실제 모달 외에는 장식 카드나 중첩 카드로 감싸지 않는다.
- 제품 예시는 실제 소스의 보드·티켓 표현을 참고하되 가상 프로젝트와 티켓만 사용한다. 렌더한 제품 예시를 로컬 PNG로 캡처해 시안에 포함한다. 사용자의 실제 티켓·파일 경로·브라우저 저장소를 가져오지 않는다. 그림을 실제 사용자 데이터나 실제 AI 실행 결과라고 소개하지 않는다.
- 국내 초기 사용자가 쉽게 이해하도록 한국어 기본, 영어 전환도 제공한다. 내부 문서 예시는 원문이며 UI 언어 전환으로 의미를 바꾸지 않는다.

- 이 자료 외 개인 폴더, AI 전역 설정, 프로젝트 데이터 파일 및 `.alpha-kanban`은 읽거나 복사하지 않는다.

## 산출물과 확인

- 이 프로젝트의 `index.html`, 필요한 로컬 스타일·아이콘·폰트·제품 PNG, 재열기·동작·참고 출처를 담은 README.
- 데스크톱 1440x900과 좁은 화면 390x844에서 첫 화면의 브랜드·시작 동작·다음 내용의 일부가 보이도록 구성한다.
- 언어 전환, 섹션 이동, 설치 요청 열기/닫기·복사, 시작 시안 이동이 동작한다. 실제 파일 권한이나 설치 동작을 호출하지 않는다.
- 이미지 로드, 가로 넘침과 텍스트 겹침, 모달 닫기만 간단히 확인한다. 대규모 앱 스모크를 반복하지 않는다.
- 생성 성공은 사용자 승인이나 제품 구현이 아니다. 승인 전 AKL-15를 진행하지 않는다.

## 확인·결정이 필요한 사항

- 사용자가 생성된 소개 시안의 배치·카피·제품 예시를 검토한 뒤 적용안과 수정 의견을 결정한다.
