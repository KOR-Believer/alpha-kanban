# 공식 문서·릴리즈 시안 검토 노트

검토일: 2026-11-03

이 파일은 제품 안내가 아닌 디자인 검토 기록이다. Local Codex로 제작한 시안에 브라우저 검토 결과를 반영했다. 제품 소스, 개인 설치 스킬과 배포 설정은 변경하지 않았다.

## 화면

- 문서: 그룹 탐색·본문·페이지 목차, 좁은 화면의 메뉴와 접는 목차.
- 검색: 제목·본문 발췌, 방향키·Enter 문단 이동, 빈 결과, 검색어 초기화, Escape 닫기와 초점 복귀.
- 릴리즈: 날짜순 목록, 기록 길이에 맞는 상세, 관련 가이드와 목록 복귀.
- 한영·라이트/다크·정식/카나리 대표 화면. 아래 검토 도구는 제품 기능이 아니다.

## 채널과 콘텐츠

정식은 기본 문서 7개, 카나리는 전체 문서 16개를 보여주는 설계 예시다. 사이드바·검색·이전/다음·관련 링크는 같은 목록을 따른다. 실제 배포의 콘텐츠나 제공 기능을 자동 검증한 결과는 아니다.

릴리즈 예시는 원본의 실제 ID·날짜·요약을 사용한다. 정식은 `2026-10-26-updates`, `2026-10-30-skill-with-app`, 카나리는 `2026-11-03-canary-baseline`이다. 제목은 요약에서 도출한 편집 제목이며 새 버전 번호를 만들지 않았다. 날짜가 같은 정식 기록은 sequence 순서를 따른다.

문서 표시를 호환성 검사로 제한한다는 오래된 로컬 릴리즈 초안은 예시에서 제외했다. 문서 정리는 선택한 파일을 미리보고 적용할 때만 저장하는 동작으로 안내한다. 원본 릴리즈 데이터는 수정하지 않았다.

## 표현과 통합

기존 의미 토큰과 `--ak-*` 별칭, Raleway → Pretendard, 정식 폴더 아이콘과 카나리 플라스크·CANARY를 사용한다. 본문 16px는 공개 문서의 읽기 밀도에 관한 제안이다. 별도 디자인 시스템이나 제품 전역 크기 변경이 아니다.

이 시안의 HTML 조작을 React 통합으로 간주하지 않는다. 제품에서는 기존 Button/Input/Dialog/Select/Badge와 언어·테마 컴포넌트를 우선 사용한다. 공개 본문은 기존 Markdown 표현을 재사용하며 로컬 파일 권한을 요청하지 않는다. 새 UI 패키지는 필요하지 않았다.

## 확인과 한계

Chrome에서 1360×900 한국어 라이트와 390×844 영어 다크 화면, 검색 결과·빈 결과·키보드 이동, 메뉴·검색 Escape와 초점 복귀, 코드 복사, 문단 주소 새로고침, 릴리즈→가이드와 뒤로/앞으로, 없는 주소를 확인했다. 해당 화면에 페이지 가로 넘침이 없었다. 시안 JavaScript 구문 검사도 통과했다.

스크린리더, 대비 수치, 글꼴 확대, 클립보드 거부, React/PWA 통합·오프라인·실제 폴더 권한 검증은 별도다. 사용자 디자인 승인이나 공개 배포 완료를 뜻하지 않는다.

## README 방향

한영 README는 한 문장 소개 → 공개 예시 한 장 → 스킬 설치 → 첫 대화와 계획·티켓 → 선택적 칸반 → docs·릴리즈·업데이트 연결 순서를 제안한다. 큰 배너·가짜 배지·개인 자료는 사용하지 않는다. 실제 README는 수정하지 않았다.


## AKD-18 설명 보완

기존 스타일을 유지하며 문서 폴더 설정·파일 위치·항목별 상속·worktree 예시와 문서 정리의 지속적인 호환 관리 목적을 보강했다. ID 발급·Owner 교정·레거시 삭제는 현재 지원 동작으로 구분한다. 설정 파일명으로 안내하며 별도 형식명을 표시하지 않는다. 한국어 라이트 데스크톱과 영어 다크 390px의 읽기 화면을 Chrome에서 확인했다. 이 보완의 구현·검증 기록은 AKD-18에 남긴다.
## 조작 가능한 사용 예시 보완

2026-11-04 사용자 요청에 따라 기존 한영 본문을 유지하고 10개 문서에 사용 예시를 추가했다. 소유자, 공유 설정, 개인 설정, 문서 정리, 이동·인수인계, 다른 PC 링크, 연결 변경·해제, 앱·스킬 업데이트, 백업 복원, 폴더 접근 복구를 다룬다.

예시는 메모리 안의 가상 데이터만 바꾸며 실제 폴더 선택·권한·IndexedDB·스킬 설치·업데이트를 실행하지 않는다. 실제 화면의 복제품이 아닌 동작 설명용 그림이며 제품 구현 때 Button/Badge/Checkbox/CodeDiff와 공통 토큰을 재사용한다. 자동 재생 없이 단계 버튼·선택·재시작을 제공한다. 캡처와 검증 결과는 상위 디자인 기록에서 관리한다.

## 설명과 예시의 읽기 순서

예시는 관련 기능의 목적·사용 조건·변경 범위를 읽은 뒤에 나온다. 소유자 문서는 경로와 Owner의 의미 뒤, 설정 문서는 기본 항목·폴더 지정 뒤와 상속·worktree 설명 사이에 배치한다. 나머지 문서의 예시는 해당 작업과 저장 범위를 설명한 뒤에 둔다. 본문과 데스크톱·모바일 목차의 순서는 같다.

업데이트·문제 해결의 현재 예시는 개념을 설명하는 시안이다. 사용자 검토에 따라 AKC-07 제품 통합에서는 실제 화면 캡처를 우선하고, 조작형 예시도 실제 앱의 진입점·버튼명·진행 순서·보호 조건에 맞춰 대조한다. 현재 예시의 화면을 실제 제품으로 그대로 사용하지 않는다.

## 문서 인계 방법 구분

인계 안내를 직접 파일 이동 후 문서 정리로 Owner를 맞추는 방법과 CLI로 이동·Owner·링크 변경을 함께 검토하는 방법으로 나눴다. 직접 이동한 문서는 현재 폴더로 분류되며 문서 정리는 선택 문서의 기록된 Owner를 교정하지만 이동에 따른 링크 복구는 하지 않는다. 한영 본문과 예시 제목에서 CLI를 유일한 인계 방법처럼 표현하지 않는다. 브라우저 파일 트리·드래그 이동은 이번 시안의 기능으로 추가하지 않았다.
