- 버전 고정 자산과 최신 확인 자료를 기존 PWA 캐시 계약에 맞춰 연결한다. 복사·다운로드는 개인 설치본 변경이나 AI 실행을 발생시키지 않는다.
- 공식 원본 비교 안내에서 버전 고정 배포로 전환할 때 한영 README의 설치 출처·요청문과 웹 표시·다운로드 대상을 같은 변경에서 맞춘다. 웹/PWA 업데이트가 개인 스킬을 갱신하지 않는다는 설명과 기존 #skill 진입을 유지한다.

제외 범위:

- AKL-10/12/13 책임의 중복 구현, 개인 전역 스킬 탐색·설치·자동 업데이트, 파서·문서 형식 변경, PWA 시작 주소 변경, 공개 태그 발행·배포
